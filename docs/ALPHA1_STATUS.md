# Alpha 1 状态

方案设计：龙娘无限好  
Mod 实现：tsymq（唐宋元明清）

## 当前实现

- 疫病：回合结束仍在手中时施加 3 层中毒。
- 旧伤：在手中时，每次打出其他牌失去 1 点生命。
- 枷锁：在手中时，每次打出其他牌受到 3 点伤害。
- 短缺：回合结束仍在手中时，下回合少抽 2 张牌。
- 腐烂：在同一手牌中时，其他牌读取为未升级；不改动永久牌组，离开手牌后恢复真实升级状态。
- 诅咒红面具：战斗开始时自身获得 1 层虚弱。
- 诅咒弹珠袋：战斗开始时自身获得 1 层易伤。
- 战士联动卡“诅咒之血”：2（升级后 1）费能力；抽到诅咒时获得 3 点力量。
- 储君联动卡“星辉护佑”：0 费能力；抽到诅咒时获得 5（升级后 8）点格挡。

1. 确保游戏 v0.110.1、BaseLib 3.4.0+。
