# Alpha 8 状态

当前版本：`v0.1.0-alpha.8`

方案设计：龙娘无限好  
Mod 实现：tsymq（唐宋元明清）

## 本轮内容

1. 校正空白：永恒、固有、保留；进入消耗牌堆时返回抽牌堆顶。
2. 烈火焚身：抽到时向抽牌堆加入两张已升级的灼烧。
3. 背叛：施加四类负面状态、降低力量与敏捷，并连续三回合损失能量。
4. 教化：永恒、固有、虚无。
5. 失重：下回合开始时反转力量和敏捷的正负值。

## 测试重点

- 检查空白从消耗牌堆返回抽牌堆顶是否会产生循环。
- 检查烈火焚身生成的两张灼烧是否均已升级。
- 检查背叛的三回合能量计数是否正确结束。
- 检查失重对正数、负数、零力量和敏捷的处理。
- 检查多人模式中的状态与随机牌生成是否同步。
