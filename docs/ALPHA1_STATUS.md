# Alpha 1 状态

方案设计：龙娘无限好  
Mod 实现：tsymq（唐宋元明清）

## 当前实现

- 疫病：回合结束仍在手中时施加 3 层中毒。
- 旧伤：在手中时，每次打出其他牌失去 1 点生命。
- 枷锁：在手中时，每次打出其他牌受到 3 点伤害。
- 短缺：回合结束仍在手中时，下回合少抽 2 张牌。
- 腐烂：卡牌、文本和隔离补丁骨架已加入；真正的“暂时失去升级”仍需游戏内确认后启用。

## 尚未声称完成

角色联动卡、遗物和“旧日残余”事件尚未进入本构建。它们依赖进一步确认原版角色池/事件 API；不会用不可验证的占位行为冒充完成。

## 游戏内验证

1. 确保游戏 v0.110.1、BaseLib 3.4.0+。
2. 将发布目录放入游戏 `mods/PerfectCurse/`。
3. 启用 Mod，在控制台分别生成五张诅咒。
4. 验证触发恰好一次、战斗结束后没有永久修改手牌升级。
