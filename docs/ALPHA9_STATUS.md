# PerfectCurse v0.1.0-alpha.9

## 本版内容

- 新增诅咒“偷窃”：在手牌中时，每打出一张其他牌失去1金币。
- 新增诅咒“寄生”的第一阶段机制：回合结束仍在手中时，将一张原版“感染”加入弃牌堆。
- “意外缺陷”的随机诅咒候选数量从10种增加至12种。
- 为“偷窃”“寄生”“烈火焚身”“背叛”“空白”和“教化”接入正式卡面插画。
- “背叛”卡面按设定表现铁甲战士背叛故障机器人。

## 当前范围

- 20张自定义诅咒。
- 30件诅咒遗物。
- 6张角色联动牌。
- 前置：BaseLib 3.4.0+。
- 游戏基线：v0.111.0 public-beta。

## 已知未完成内容

- “寄生”生成敌人的第二阶段机制尚未接入，需要先验证当前游戏的战斗生成接口。
