# 更新进度

当前发布版本：`v0.1.0-alpha.8`  
换版规则：每累计完成 5 次内容更新，才升级一次测试版本。

方案设计：龙娘无限好  
Mod 实现：tsymq（唐宋元明清）

## Alpha 2 已发布

1. 加入战士“诅咒之血”、储君“星辉护佑”及对应能力，并补齐占位资源。
2. 加入故障机器人“意外缺陷”，使用同步战斗随机流生成自定义诅咒。
3. 加入猎手“顺势而毒”：抽到诅咒时立即结算其负面效果并消耗，然后使所有敌人中毒。
4. 加入故障机器人“强化熔炼”：攻击并抽牌，可跨三个战斗牌堆消耗一张诅咒来重复效果。
5. 建立统一的诅咒立即结算接口，五张自定义诅咒均可被联动效果安全调用，并为原版回合末诅咒提供兼容回退。

五次更新已完成，正式升级为 `v0.1.0-alpha.2`。

## Alpha 3 已发布：5 / 5

1. 为两件诅咒遗物加入原版遗物伪装、拾取后揭示和 `IsRevealed` 存档字段。
2. 补齐诅咒遗物在普通悬浮、商店、奖励和事件预览中的说明伪装入口。
3. 校正原版伪装遗物的本地化键，并在拾取揭示后主动刷新图标与提示状态。
4. 补齐诅咒遗物的原版轮廓图和大图伪装，避免奖励放大预览提前泄露真实身份。
5. 补齐伪装遗物风味文本入口，完成名称、说明、风味与三类图标的统一伪装覆盖。

五次更新已完成，正式升级为 `v0.1.0-alpha.3`。下一轮重新从 0 / 5 计数。

## Alpha 4 发布前的更新计数：5 / 5

1. 为疫病、腐烂、旧伤、枷锁、短缺生成并接入统一风格的正式卡面插画，包含 250×190 普通图和 1000×760 大图。
2. 为咒血、星光神盾、意外故障、乘毒而行、强化熔炼生成并接入正式卡面插画，同时按诅咒卡与角色卡分类归档原始美术资源。
3. 加入骨妹联动卡“恶意注能”：立即召唤 5，且可消耗一张手牌诅咒，在下回合开始时再次召唤 5（升级后 8）。六张角色联动卡至此全部进入构建。
4. 加入色欲、偏见、失忆三张禁用牌型诅咒；只在诅咒位于对应玩家手牌时生效，分别阻止攻击、技能和能力牌，并向原版出牌判定返回阻止来源。
5. 加入“野蛮”诅咒：固有、保留，位于手牌中时将该玩家获得的格挡乘数归零，同时覆盖卡牌格挡预览和实际结算。

五次更新已完成，正式升级为 `v0.1.0-alpha.4`。下一轮重新从 0 / 5 计数。

## Alpha 5 已发布：5 / 5

1. 加入发霉草莓、有毒梨子、蛀虫芒果三件伪装诅咒遗物；分别伪装为原版草莓、梨子、芒果，拾取揭示后失去 7、10、14 点生命上限，最低保留 1 点生命上限。
2. 加入诅咒之锚、诅咒夹板、诅咒舵盘三件伪装遗物；分别在第 1、2、3 回合临时失去 1、2、3 点敏捷，并在该回合结束时由原版临时敏捷机制自动恢复。
3. 加入诅咒灯笼、诅咒烛台、诅咒吊灯三件伪装遗物；分别在第 1、2、3 回合能量重置后失去 1、2、3 点能量，避免扣除被回合能量重置覆盖。
4. 加入转咒轮、诅咒雕像、遭诅历石三件伪装遗物；分别移除普通敌人的卡牌奖励、移除战斗胜利后的药水奖励，并在第 7 回合结束时对自己和队友造成 26 点伤害。
5. 加入科学打火机、永生种子、诅咒熔岩灯三件伪装遗物；分别使附魔攻击牌少造成 9 点伤害、令基础打击与防御获得永恒，并在战斗中失去生命后移除该场战斗的卡牌奖励。

五次更新已完成，正式升级为 `v0.1.0-alpha.5`。下一轮重新从 0 / 5 计数。

## Alpha 6 已发布：5 / 5

1. 加入腐朽臂甲、遭诅礼帽、炸膛大炮三件伪装遗物；分别使每场战斗第一张提供格挡的卡牌格挡减半、获得金币减少 25%，以及升级攻击牌少造成 1 点伤害。
2. 加入腐朽羽毛、断裂双截棍、过期小血瓶三件伪装遗物；分别按牌组每 10 张牌在进入休息处时失去 3 点生命、每打出 5 张攻击牌失去 1 点能量，以及每场战斗第 1 回合开始时失去 1 点生命。
3. 加入破损的药水腰带、意外粗糙的石头、断裂金刚杵三件伪装遗物；分别在拾取时失去 2 个药水栏位，并在每场战斗开始时失去 1 点敏捷或 1 点力量。
4. 加入停止的摆动球；每第 3 个自身回合开始抽牌时少抽 1 张，并保存跨存档及跨战斗的回合计数。
5. 加入诅咒星图、诅咒穷鬼卡、生蛆面包三件伪装遗物；分别在进入问号房时失去 1 点生命、使商店价格增加 100%，以及第 1 回合额外获得 2 点能量但之后每回合少获得 1 点能量。

五次更新已完成，正式升级为 `v0.1.0-alpha.6`。下一轮重新从 0 / 5 计数。

## Alpha 7 已发布：5 / 5

1. 加入可打出的 0 费诅咒“自逊”：虚无、消耗，打出后获得 99 层缩小；同时建立通用的“必须优先打出”诅咒规则，自逊在手牌中时会阻止其他牌打出。
2. 加入 1 费诅咒“暴食”：必须优先打出，失去 23 点生命并获得 5 点生命上限，随后消耗；同时将自逊和暴食加入“意外缺陷”的同步随机诅咒池。
3. 加入 X 费诅咒“自毁”：永恒、保留、必须优先打出；按实际支付的 X 恢复等量能量，同时失去 X 点生命上限并消耗。
4. 加入诅咒“解离”：回合结束时若仍在手牌中，下个自身回合在抽牌前获得原版混乱，并在该回合结束时仅移除由解离施加的混乱；同时加入“意外缺陷”的同步随机诅咒池。
5. 加入循环诅咒“空白”：每当进入弃牌堆时自动移动到抽牌堆顶；同时将其加入“意外缺陷”的同步随机诅咒池，使候选数量增加至 9 种。

五次更新已完成，正式升级为 `v0.1.0-alpha.7`。下一轮重新从 0 / 5 计数。

## Alpha 8 已发布：5 / 5

1. 按设计表校正“空白”：补齐永恒、固有、保留，并将循环触发条件由进入弃牌堆改为进入消耗牌堆；进入消耗牌堆后自动返回抽牌堆顶。
2. 加入诅咒“烈火焚身”：保留，抽到时向抽牌堆加入两张各升级一次的原版灼烧；同时加入“意外缺陷”的同步随机诅咒池，使候选数量增加至 10 种。
3. 加入诅咒“背叛”：永恒、固有，回合结束仍在手中时获得3层易伤、虚弱、缩小与脆弱，失去3点力量和敏捷，并在接下来3个自身回合开始时各失去1点能量。
4. 加入诅咒“教化”：永恒、固有、虚无；进入战斗时占用初始手牌，并在未被其他效果处理时于回合结束自动进入消耗牌堆。
5. 加入诅咒“失重”：回合结束仍在手中时安排下回合效果；下个自身回合开始时将当前力量和敏捷由正数变负数、负数变正数，零值保持不变。

五次更新已完成，正式升级为 `v0.1.0-alpha.8`。下一轮重新从 0 / 5 计数。

## Alpha 9 已发布：5 / 5
