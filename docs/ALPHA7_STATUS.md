# Alpha 7 状态

当前版本：`v0.1.0-alpha.7`

方案设计：龙娘无限好  
Mod 实现：tsymq（唐宋元明清）

## 本轮内容

1. 自逊：0 费优先诅咒，获得 99 层缩小。
2. 暴食：1 费优先诅咒，失去 23 点生命并获得 5 点生命上限。
3. 自毁：X 费优先诅咒，返还 X 点能量并失去 X 点生命上限。
4. 解离：下回合临时获得混乱，且只移除自身施加的混乱。
5. 空白：进入弃牌堆后自动返回抽牌堆顶。

“意外缺陷”的同步随机诅咒池现包含 9 种候选。

## 测试重点

- 确认空白因回合弃牌或其他弃牌效果进入弃牌堆时，会回到抽牌堆顶。
- 确认空白从弃牌堆移动后不会重复触发或造成无限循环。
- 确认多人战斗中的随机诅咒生成保持同步。
- 确认解离不会移除其他来源施加的混乱。
